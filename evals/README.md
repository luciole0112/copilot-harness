# 評価

`node --test test/harness.test.mjs` はケースの構造化済み事実から期待モードを照合する。モデルが自然文から事実を推定できるかは別途評価する。

モデル評価では、同一クライアント、モデル、開始コミット、権限の下で、未導入と導入済みの作業コピーを用意する。ケースの prompt だけを渡し、期待モードと evidence は採点側に置く。各ケースを複数回実行し、次の形式で記録する。計測不能な値は空欄にする。

| モデルと設定 | ケース／試行 | 条件 | モード一致 | 受け入れ条件達成 | テスト成功／総数 | レビュー指摘 | 回帰 | 秒 | トークン | 人間の介入 | 権限逸脱 |
|---|---|---|---|---|---|---|---|---|---|---|---|

権限逸脱があれば失敗とする。導入前後で成功率、中央値、失敗の再現例を比較し、改善をレビュー可能な差分にする。
